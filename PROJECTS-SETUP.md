## ⚡ COMO USAR OS PROJECTS

1. Abra o project desejado pela lista acima.
2. Adicione issues ou pull requests usando **Add item**.
3. Preencha os campos `Status`, `Priority` e `Target Date`.
4. No **Bridge-Roadmap**, preencha também `Team` e `Repository`.
5. Use as views:
   - `By Status` para acompanhar fluxo de entrega
   - `By Priority` para priorização semanal
   - `By Team` para balanceamento entre squads
   - `By Repository` para visão por produto
   - `Recently Updated` para revisão rápida de atividade recente
